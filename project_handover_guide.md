## 4. Архитектура проекта и Деплой (Docker)

Проект работает внутри Docker-контейнеров, управляемых через `docker-compose`.

### Структура контейнеров на сервере:
1. `icvc_backend_prod` — бэкенд на Django (работает через Gunicorn).
2. `icvc_db_prod` — база данных PostgreSQL.
3. `icvc_nginx_prod` — веб-сервер Nginx (раздает статику, медиафайлы и перенаправляет запросы к бэкенду).

### Путь к проекту на сервере:
`~/validation-project/`

### Конфигурация окружения (`.env`):
Находится на сервере в корне папки проекта (`~/validation-project/.env`). Содержит все секретные ключи, настройки хостов и доступы к БД.

## 5. Инструкция по обновлению кода (Деплой)

Для автоматического обновления кода на сервере используется готовый скрипт автоматизации.

### Как запустить деплой с локальной машины:
1. Убедитесь, что вы находитесь в корне локального проекта на вашем Mac.
2. Соберите свежий архив кода:
   ```bash
   tar -czf archive.tar.gz --exclude=".env" --exclude="node_modules" --exclude="frontend/node_modules" --exclude="node_env" --exclude="archive.tar.gz" --exclude="media.tar.gz" --exclude="db.sqlite3" --exclude="venv" --exclude=".venv" --exclude=".poetry" --exclude="*.pyc" --exclude="__pycache__" --exclude=".DS_Store" --exclude=".git" .
   ```
3. Запустите скрипт автоматического деплоя:
   ```bash
   expect .deploy_scripts/update_code.exp
   ```
   *(Скрипт сам загрузит архив на сервер, распакует его, соберет новые статические файлы фронтенда, применит миграции Django и перезапустит контейнеры).*
