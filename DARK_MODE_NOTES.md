# Руководство по интеграции и улучшению темной темы (Dark Mode)

Данная ветка `feature/dark-mode-redesign` содержит полную реализацию темной темы для портала ЦНСВ при МП КР (frontend).

## Что реализовано:
1. **Инфраструктура (`ThemeContext.tsx`, `tailwind.config.js`)**:
   - `darkMode: 'class'`.
   - Полноценный контекст темы с сохранением выбора в `localStorage` (`theme` = `'light'` | `'dark'`).
   - Синхронное переключение класса `.dark` на элементах `html` и `body`.
   - По умолчанию установлена светлая тема (`light`), чтобы не сбивать пользователей с системной темной темой macOS/Windows.

2. **Шапка и Навигация**:
   - Кнопка переключения темы (Солнце ☀️ / Луна 🌙) в `Toolbar.tsx`.
   - Автоматическая подмена логотипа:
     - Светлая тема: `/src/assets/logo-dark-bg-ru.svg` (или `kg`).
     - Тёмная тема: `/src/assets/logo-white-transparent-ru.svg` (чистый белый векторный логотип).
   - Цвет навбара: в светлой теме `#283375`, в тёмной теме глубокий ночной `#141b36`.

3. **Стилистика и страницы**:
   - Фон сайта: глубокий контрастный оттенок `#080b18` с радиальной виньеткой.
   - Устранены белые артефакты по углам шапки (`rounded-2xl overflow-hidden`).
   - Стилизованы все основные разделы и страницы:
     - Главная страница (`Home.tsx`, `HeroSection.tsx`, `NewsSection.tsx`, `StatisticsSection.tsx`)
     - Новости (`NewsList.tsx`, `NewsCard.tsx`)
     - Реестр сертифицированных лиц (`CertifiedUsers.tsx`, карточки, поиск)
     - Профессиональные стандарты (`ProfStandards.tsx`)
     - Центры оценки (`AssessmentCenters.tsx`)
     - Партнёры (`Partners.tsx`)
     - Медиа (Галерея видео и фото `VideoGallery.tsx`, `ImageGallery.tsx`)
     - Руководство (`Management.tsx`)
     - Дополнительная информация и нормативные документы (`AdditionalInfo.tsx`, `DocumentCard.tsx`)
     - База экспертов (`Experts.tsx`)
     - Интерактивные сервисы: «Электронная приемная» (`Apply.tsx` + шаги 1–4), «Статус заявки» (`ApplicationStatus.tsx`), модальное окно консультации (`CallbackModal.tsx`).

## Рекомендации для будущих доработок перед мерджем в main:
- **Детальная страница новости (`NewsDetail.tsx`)**: проверить рендеринг Rich Text / HTML-контента из Django-админки (добавить класс `.prose-invert` для `prose` при `.dark`).
- **Страница детального просмотра центра оценки (`AssessmentCenterDetail.tsx`)** и партнёра (`PartnerDetail.tsx`): при необходимости добавить адаптацию таблиц/аккордеонов под тёмную тему.
- **Страница проверки подлинности сертификата (`VerifyCertificate.tsx`)**: добавить стили для поля ввода QR/номера сертификата.
- **Favicon**: при желании можно добавить SVG-favicon с медиа-запросом `(prefers-color-scheme: dark)`.
